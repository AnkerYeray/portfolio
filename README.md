## Portfolio
Portfolio personal desarrollado en la materia Desarrollo Web Frontend.
Link a vercel: https://portfolio-sigma-lime-62.vercel.app/


Documentación Técnica del Proyecto

Descripción General:
Este proyecto es una página web de portfolio personal desarrollado para la materia Desarrollo de Sistemas Web (frontend), incluyendo perfil profesional, habilidades, proyectos y enlaces a redes sociales. Se optó por un diseño limpio y minimalista para mejorar la experiencia del usuario y reducir la saturación visual. A su vez, se hizo foco en la sostenibilidad y accesibilidad digital. 


Tecnologías Usadas:
HTML5 como lenguaje de etiquetado para dar estructura al sitio. 
CSS3 para el diseño visual y la disposición de los elementos, permitiendo un diseño responsivo y atractivo, asegurando una experiencia de usuario fluida en diferentes dispositivos.


Accesibilidad y sostenibilidad digital:
En el desarrollo del sitio se buscó priorizar una perspectiva de sostenibilidad y accesibilidad. En ese marco las etiquetas semánticas (como < header >, < nav >, < main >, < section >, y < ul > ), la declaración de lenguaje (lang="es") en la etiqueta < html > y la descripción detallada en el atributo "alt" de cada imágen se vuelven fundamentales ya que ayudan -principalmente- a los lectores de pantalla a interpretar correctamente el contenido, mejorando la experiencia de usuarios con discapacidades.
A su vez, se utilizó el formato webp para las imágenes reduciendo su peso sin perder calidad, lo que optimiza la utilización de recursos. 


Diseño Responsivo:
La estructura del código permite la integración de estilos CSS responsivos para adaptarse a diferentes tamaños de pantalla.

Enlaces de Navegación:
Los enlaces en el menú de navegación utilizan anclas (href="#inicio") para facilitar el desplazamiento dentro de la página, lo que mejora la experiencia del usuario al permitir un acceso rápido a secciones específicas.

Declaración de uso de IA: Se utilizó Github Copilot como asistente para la elaboración de esta documentación técnica, la cual fue modificada posteriormente por mi.
