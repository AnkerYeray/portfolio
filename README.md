## Portfolio
Portfolio personal desarrollado en la materia Desarrollo Web Frontend


Documentación

  Descripción general:
  Esta aplicación web está diseñada para ofrecer a los usuarios una interfaz intuitiva y sencilla.

  Decisiones clave:

  1. Diseño de la interfaz de usuario:
     - Se optó por un diseño limpio y minimalista para mejorar la experiencia del usuario y reducir la saturación visual.
     - Se aplicaron principios de diseño responsivo para garantizar la compatibilidad con diversos dispositivos (ordenadores de escritorio, tabletas y teléfonos inteligentes).

  2. Stack tecnológico:
     - La aplicación se ha desarrollado utilizando HTML y CSS, garantizando una experiencia de usuario rápida y fluida.

  4. Accesibilidad:
     - Se integraron funciones de accesibilidad para garantizar que la aplicación pueda ser utilizada por personas con discapacidad, siguiendo las pautas WCAG.
       
  5. Futuras mejoras:
     - Actualmente la web tiene un diseño sencillo y detalles estéticos a mejorar
     - Se implementará una sección de proyectos


  Conclusión:
  Las decisiones tomadas durante el desarrollo de esta aplicación web tuvieron como objetivo crear una plataforma eficiente y fácil de usar. Se buscará obtener retroalimentación continua para mejorar y adaptar la aplicación a las necesidades de los usuarios.
